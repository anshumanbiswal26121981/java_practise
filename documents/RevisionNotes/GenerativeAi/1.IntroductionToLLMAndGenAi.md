Revision Notes: Introduction to AI and LLMs
Overview
This session serves as an introductory guide to understanding the basic vocabulary and concepts in the realm of Artificial Intelligence (AI), with a particular focus on Large Language Models (LLMs). The objective is to familiarize you with key terms and concepts that will be foundational for future classes.

AI Vocabulary
AI (Artificial Intelligence)
AI is a broad term for computer systems that can perform tasks that require human-like intelligence. These tasks include image recognition, natural language processing, decision-making, and playing games like chess .

Narrow vs. General AI
Narrow AI: What exists today; designed to handle one specific task (e.g., spam filters, face recognition).
General AI: Hypothetical AI that could perform any intellectual task a human can do .
Generative AI
Generative AI refers to systems that create new content. While traditional AI techniques classify and predict, generative AI can write, draw, compose, and code .

LLM (Large Language Model)
LLMs are a subset of AI, products of deep learning within machine learning, capable of generating human-like text by predicting the next word in a sentence .

AI Agents
An AI Agent extends beyond simple chat responses by performing tasks such as booking flights or making reservations autonomously. It uses tools, retains memory of past interactions, and can make autonomous decisions .

Core Concepts in LLMs
Tokens
Tokens are the smallest units of text that an LLM processes, much like LEGO bricks for text. Each part of a word, punctuation, or even spaces can be a token .

Importance:
Billing: API usage is typically metered by the number of tokens processed.
Context Limits: Models have a limited number of tokens they can process at one time .
Context Window
A context window refers to the amount of information (in tokens) an LLM can handle at once. It's likened to the size of a desk—fit for small tasks or large conferences depending on its size .

Temperature
Temperature is a parameter in LLMs that controls the randomness of predictions. A lower temperature makes the model output more deterministic and focused, while a higher temperature allows for more varied and creative responses .

Introduction to Tooling
APIs
Application Programming Interfaces (APIs) are crucial for building AI tools as they serve as the interface between different software applications .

Google Colab
Google Colab is an online platform where you can write and execute code in Python. It’s particularly useful for data science and AI projects .

JSON and Terminal
JSON (JavaScript Object Notation): A data interchange format used widely in APIs for structuring data in a readable format.
Terminal: A command-line interface used to interact with the operating system, essential for navigating file systems and running scripts .
GitHub
A platform for code hosting and version control, enabling collaboration among developers .

Architecture
Understanding backend, frontend, and databases is necessary for integrating AI in real-world applications, where APIs connect these components .

Summary
This class sets the foundation for exploring AI applications by equipping you with essential vocabulary and tools. Understanding these fundamentals is crucial as AI continues to advance and integrate into software engineering practices .
